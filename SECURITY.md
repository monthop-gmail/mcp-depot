# Security policy

## Reporting a vulnerability
Please **do not open a public issue**. Use GitHub's private vulnerability reporting:
*Security* tab → *Report a vulnerability*. We aim to acknowledge within 7 days.

Especially relevant here: anything that lets a request reach a tool without a verified identity, bypasses the
guard or default deny, leaks tokens or membership data, or lets a tool act outside its declared scope.

## Scope
This repository's code and default configuration. Your own Cloudflare Access, portal and site configuration are
outside scope, but reports showing that our defaults lead to an unsafe setup are welcome.

## Supported versions
Design phase: only `main`.
